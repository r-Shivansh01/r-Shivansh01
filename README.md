### 🚀 Featured Projects

Here are some of the key projects I've been working on:

#### 🏆 **[Fièrté](https://github.com/r-Shivansh01/Fierte_v1)**
A next-generation AI-powered habit tracker. Features a complete dashboard, automated AI evaluations of user progress, and a seamless flow from frontend (Next.js/React) to a robust backend. 

#### ⏳ **[Time Capsule](https://github.com/r-Shivansh01/TimeCapsule)**
A digital time capsule experience wrapped in a highly interactive, cinematic UI. Built with modern web technologies to preserve memories and messages in a visually stunning "synthesizer" aesthetic.

#### 📚 **[Libris](https://github.com/r-Shivansh01/Libris)**
A beautifully designed platform tailored for book enthusiasts and modern readers. *(Check out the repository for more details!)*

#### 🤖 **[GitGuard AI](https://github.com/r-Shivansh01/GitGuard_AI)**
An intelligent GitHook for GitPush. Leverages AI to review commits and safeguard repositories against sensitive data leaks or poor code quality before they are pushed.

#### ☁️ **CloudLab_01**
A Python-based server health checker built while experimenting with my home lab on Oracle Cloud (ARM).
